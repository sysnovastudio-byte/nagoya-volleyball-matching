# 名古屋バレーボール募集・参加マッチングアプリ

**「バレーしたい人、集まれ！」**

一人でも、初心者でも、気軽にバレーを楽しもう。

## プロジェクト概要

名古屋市内でバレーボールをしたい参加者と、参加者を集めたい主催者をつなぐWebアプリです。20代・30代を中心に、年齢制限は設けず、未経験者から経験者までを対象とします（18歳未満は保護者の同意の申告が必要で、募集は作成できません。法的な条件は公開前に確認します）。

## 開発状況

**初期構築（資料作成）の段階です。アプリのプログラムは未実装です。**

## 主な機能（初期リリース予定）

MVP優先のアジャイル開発で進めます。「募集を探す → 詳細を見る → 参加申請する → 主催者と連絡する」を最優先とし、必要最小限の機能から公開します。次は見直し前の一覧で、MVPの範囲は確認中です。

- メールアドレス＋パスワードによる登録・ログイン、メール認証
- ログイン不要の募集閲覧
- 募集の作成と、主催者による参加の承認・却下
- 定員管理、キャンセル、主催者への通知
- 参加申請前から使えるチャット
- 承認済みユーザーだけへの詳細住所の公開
- 通報、ブロック、管理者による利用停止
- プロフィール

詳細は [機能一覧](docs/04_機能一覧.md) を参照してください。

## 開発環境のセットアップ方法

1. Git、VS Codeを用意する
2. GitHub CLIを用意し、`gh auth login` でログインする
3. リポジトリを取得する

   ```powershell
   gh repo clone <GitHubアカウント>/nagoya-volleyball-matching
   cd nagoya-volleyball-matching
   code .
   ```

4. Node.jsは、採用バージョンの決定後に導入する

アプリの起動手順は実装開始後に追記します。詳細は [技術構成・開発環境](docs/05_技術構成・開発環境.md) を参照してください。
