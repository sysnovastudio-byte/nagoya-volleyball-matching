# 00 索引

資料を読む前に、ここで場所を調べ、必要な章だけを読む。章の行は `grep -n '^#' docs/<資料>.md` で調べ、その範囲だけを開く。

- この索引は場所の案内であり、仕様ではない。内容は各資料を正とする
- docs を更新したら（章の追加・削除・移動、番号の追加・決定）、この索引も同じコミットで直す
- `PROJECT_HANDOVER.md` は会話の整理で、確定仕様ではない（docs と矛盾したら docs を正とし、報告する）
