## 1. サービスの目的【合意済み】

バレーボールをしたい参加者と、参加者を集めたい主催者をつなぐWebアプリを提供する。

## 2. コンセプト【合意済み】

**「バレーしたい人、集まれ！」**

「一人でも、初心者でも、気軽にバレーを楽しもう。」

## 3. 対象【合意済み】

| 項目 | 内容 |
|---|---|
| 対象地域 | 愛知県全域（名古屋市を中心とする）【2026-11-27 ユーザーの決定】。元は名古屋市内【合意済み】 |
| 主な対象 | 20代・30代を中心とする男女。**登録は20歳以上**【2026-11-27 ユーザーの決定】。元の「年齢制限は設けない」【合意済み】を改めた |
| 経験レベル | 未経験者・初心者・経験者 |
| 参加形式 | 一人参加・友人同士の参加 |
| 利用目的 | 気軽な運動、趣味、友達づくり、バレーボールを楽しむ |

登録時に「20歳以上です」と申告する【2026-11-27 ユーザーの決定】。未成年者は登録できず、保護者の同意や18歳未満の区分は設けない（11の7-1）。法的な条件は公開前に確認する（Q-30）。

## 4. 解決する課題

以下は合意済みの対象・機能から整理した**仮説**であり、利用者調査で検証したものではない。

| 立場 | 課題（仮説） | 本サービスでの対応 |
|---|---|---|
| 参加者 | 一人では参加先を見つけにくい | ログインなしで募集を閲覧できる |
| 参加者 | 初心者が参加してよいか分からない | 参加申請前に主催者へ質問できる |
| 参加者 | 知らない相手との交流が不安 | 通報・ブロック・利用停止、連絡先の非公開 |
| 主催者 | 人数を集めにくい | 募集を公開し、参加申請を受け付けられる |
| 主催者 | どんな人が来るか分からない | プロフィールと承認制 |
| 主催者 | 人数管理が手間 | 定員管理、キャンセル通知、残り枠数の更新 |
| 主催者 | 開催場所を広く公開したくない | 詳細住所は承認済みユーザーだけに公開 |

## 5. サービスの特徴【合意済み】

1. 募集はログインなしで閲覧でき、参加申請とは区別する
2. 主催者による承認制
3. 参加申請前から主催者に質問できる
4. メールアドレス・電話番号は公開しない。詳細住所は承認後に公開する
5. 通報・ブロック・管理者による利用停止を初期リリースから備える

## 6. 開発方針【合意済み】

- アジャイル方式を採用する
- 最初からすべてを完成させず、必要な機能から実装し、実際に利用して改善する
- 初期費用はできるだけ無料に抑える
- 開発者は基本的に1人。AI開発支援としてClaude Codeを利用する
